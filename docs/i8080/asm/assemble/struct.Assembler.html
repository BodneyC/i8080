fn parse_at( &mut self, lines: Vec<LineMeta>, load_address: u16, ) -> Result<(), ParserError>

First pass over the source

Labels are defined, IFs are evaluated, macros are recorded, and every remaining line is given its address and width ready for code generation.

As labels are defined in a single pass, any expression evaluated here (IF, ORG, EQU, SET, DB, DS) may only use labels defined earlier in the source.
