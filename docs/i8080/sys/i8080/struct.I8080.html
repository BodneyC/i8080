pub fn cycle(&mut self)

Fetch and execute a single instruction, or a pending interrupt if interrupts are enabled

PC is advanced past the instruction before it executes so that jumps, calls, and returns can overwrite it, and so CALL pushes the address of the following instruction. An interrupt instruction is not fetched from memory so PC is left as is.
